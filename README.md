# AzLove

AzLove Azərbaycanda tanışlıq üçün sadə Telegram botudur.

## Xidmətlər

- Profil yaratmaq və ya yeniləmək
- Uyğun profillərə baxmaq
- Bəyənmə əsasında qarşılıqlı uyğunlaşma
- Profil məlumatını göstərmək
- İstifadə qaydaları bölməsi

## Quraşdırma

1. Asılılıqları quraşdırın:

```bash
pip install pytelegrambotapi
```

2. `TELEGRAM_API_KEY` mühit dəyişənini təyin edin:

```bash
export TELEGRAM_API_KEY="TOKENINIZI_YAZIN"
```

3. Botu işə salın:

```bash
python bot.py
```
